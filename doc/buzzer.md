# Buzzer 程序文档

- 使用 `esp_timer` 作为驱动
- 使用 `nvs_flash` 作为蜂鸣器开关控制持久化状态

## Buzzer 模块负责的工作是什么？

- 按键每按一下，蜂鸣器就“滴”一下
- 蜂鸣器有一个设置项控制是否使能蜂鸣器（nvs保存状态，重启不丢失）
- 报警输出功能（如：温度报警时[滴-滴间隔循环一直响，直到手动关闭时取消报警]

## 怎么实现：按键每按一下，蜂鸣器就“滴”一下

基本思路是按键按一下时打开蜂鸣器，并同时打开一个定时器，设定要响多久（如:按一下按键使蜂鸣器响 0.5s后关闭。

## 怎么实现报警输出

> 报警输出功能（如：温度报警时[滴-滴间隔循环一直响，直到手动关闭时取消报警]

基本思路是报警时进入循环报警，有标志位决定什么时候退出。
